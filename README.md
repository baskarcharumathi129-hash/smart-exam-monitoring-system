# Smart Exam Monitoring System

A smart examination monitoring system designed to improve exam security using student identity verification, registered device binding, BLE-based nearby device detection, invigilator alerts, and Firebase-based exam management.

## Main Modules

- Student App
- Invigilator App
- Admin App
- Backend
- Firebase
- BLE Monitoring

## Key Features

- Student Login
- College ID Verification
- Exam Schedule
- Registered Device Binding
- Exam Hall Verification
- BLE Device Detection
- Invigilator Alerts
- Exam Monitoring Logs
- Admin Management

## Technologies

- React Native
- Node.js
- Express.js
- Firebase
- Firestore
- Firebase Authentication
- Bluetooth Low Energy (BLE)
- Git & GitHub
